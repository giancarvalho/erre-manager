# erre-manager

Plataforma de gestão de comunidades, organizada em módulos. O primeiro módulo é o **Errômetro**, migrado do repositório legado [`giancarvalho/queridometro`](https://github.com/giancarvalho/queridometro). No legado ele também aparece como Queridômetro ou Karmômetro; é tudo a mesma coisa.

O repositório está em fase de planejamento. Comece por aqui:

| Documento | Para quê |
|---|---|
| [`AGENTS.md`](AGENTS.md) | Regras obrigatórias para qualquer agente ou pessoa que trabalhe aqui |
| [`docs/migration/PLANO.md`](docs/migration/PLANO.md) | Plano em 20 sprints, com tarefas, entregáveis e critérios de aceite |
| [`docs/migration/ARQUITETURA.md`](docs/migration/ARQUITETURA.md) | Arquitetura-alvo, contrato de módulo, multi-tenancy e RLS |
| [`docs/migration/DECISOES.md`](docs/migration/DECISOES.md) | Registro de decisões (o que já foi decidido e por quê) |
| [`docs/migration/PERGUNTAS.md`](docs/migration/PERGUNTAS.md) | Perguntas em aberto que dependem do humano |
